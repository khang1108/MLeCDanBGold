\section{Related Work}
\label{sec:related-work}

Interactive video retrieval systems at VBS combine multimodal retrieval with
mechanisms for query refinement, browsing, and relevance feedback.
VISIONE supports multiple textual, visual, and temporal search modes
~\cite{amato2022visione,amato2023visione,amato2024visione}, while PraK and
Exquisitor provide mechanisms for query reformulation and relevance feedback
~\cite{lokoc2024prak,khan2024exquisitor,sharma2025exquisitor}. Prior VBS
evaluations further show that successful interactive search depends not only on
the initial retrieval ranking, but also on iterative query refinement and
result inspection~\cite{schall2024interactive,jackl2026interaction}. These
approaches expose interactions over queries and retrieved results; SHI instead
also exposes the system's event-level interpretation of a multi-event request
as an explicit, editable \emph{Query Hypothesis}.

Temporal structure has also been incorporated into interactive video retrieval.
vitrivr supports temporally contextualized multimodal queries
~\cite{heller2022temporalqueries}, and Exquisitor 2026 introduces sequence-chain
retrieval for multi-event temporal search~\cite{khan2026temporalqueries}.
Interactive moment-retrieval approaches have additionally used user feedback to
refine subsequent navigation through candidate moments~\cite{ma2022ivcmr}.
These methods primarily refine queries, rankings, or navigation. In contrast,
\emph{EventTrail} exposes the current temporal hypothesis for a candidate video
itself, allowing users to inspect and correct event occurrences while preserving
the context of the complete ordered event sequence.
