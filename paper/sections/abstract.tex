\begin{abstract}
Multi-event video retrieval under live competition constraints requires interpreting
a textual narrative as an ordered sequence of retrievable events and aligning those
events with occurrences within candidate videos. If users rely solely on query
reformulation and result inspection, they cannot directly inspect how the system
decomposes the narrative or selects an occurrence for each event. We present SHI,
a human-in-the-loop video retrieval system that integrates two mechanisms for
inspecting and correcting these decisions: (1) \emph{Query Hypothesis}, which
lets users inspect and revise an ordered event decomposition grounded in the
original description; and (2) \emph{EventTrail}, which exposes the temporal
alignment of the complete event sequence within a candidate video. EventTrail
presents alternative occurrences in the context of complete ordered paths,
allowing users to retain the current match, select an alternative, or reject a
temporal region. User selections are treated as temporal feedback: retaining or
selecting an occurrence creates an anchor constraint, while rejecting a temporal
region creates an exclusion constraint. SHI then re-decodes the complete
alignment under these constraints.

\end{abstract}
