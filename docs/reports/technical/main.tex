    \textbf{Abstract---}
    We present an interactive multimodal video-retrieval system for Known Item
    Search (\KIS) and Temporal Retrieval and Alignment of Key Events (\TRAKE).
    The system converts a canonical keyframe corpus into complementary visual,
    scene-context, transcript, and lexical evidence. SigLIP2 represents images
    and visual-language queries; Qwen3-VL, Florence-2, YOLOE, Qwen3-ASR, and
    pyannote enrich frames and time intervals; BGE-M3 embeds serialized
    \FrameContext{} and speech segments. L2-normalized vectors are stored in
    exact inner-product \FAISS{} indexes, while a fielded BM25 index preserves
    literal title, caption, OCR, and ASR matches. Detached frame retrieval uses
    weighted reciprocal-rank fusion. In contrast, \KIS{} and \TRAKE{} construct
    full-corpus event--frame score matrices, calibrate and fuse available
    evidence per event and frame, and decode strict chronological paths with a
    linear-time monotonic dynamic program. A React interface supports search,
    evidence inspection, frame-accurate video navigation, history replay, and a
    revision-aware shared submission workspace. Offline GPU jobs and optional
    inference services can run on disposable Thunder Compute instances while
    canonical metadata, indexes, and collaborative state remain local or in S3.
    The appendix provides the architecture, artifact/model inventory, and live
    interface evidence; the first four pages deliberately contain only prose
    and equations.
  \end{minipage}
