\section{Introduction}
\label{sec:introduction}

The Video Browser Showdown (VBS) evaluates interactive video retrieval systems
through live search tasks over large-scale video collections~\cite{vbs2027cfp}.
Among these tasks, multi-event Known-Item Search (KIS) requires an operator to
locate a video described by a sequence of temporally ordered events~\cite{vbs2027cfp}. Compared
with single-event retrieval, this setting introduces two additional sources of
uncertainty: the narrative must first be decomposed into suitable retrieval
events, and the retrieved evidence must then be aligned to occurrences that
satisfy the intended temporal order. Errors in either stage can affect candidate
ranking and complicate subsequent inspection. However, these intermediate
decisions are often handled internally by the retrieval pipeline, leaving
operators to infer how a narrative was interpreted or why particular temporal
occurrences were selected from the returned results\cite{amato2024visione,lokoc2024prak,sharma2025exquisitor,heller2022temporalqueries,khan2026temporalqueries}.

LLMs provide a convenient way to convert unstructured narratives into structured
event sequences. Prior work on complex task understanding shows that LLMs can
identify individual task steps effectively, while still exhibiting difficulty
in predicting temporal dependencies between those steps~\cite{yuan2024tasklama}.
This distinction is particularly relevant to multi-event video search, where an
apparently plausible decomposition may still contain event boundaries or ordering
assumptions that do not match the operator's intended search strategy. If such a
decomposition is executed directly, its errors may propagate to multimodal
scoring and temporal alignment. We therefore treat the LLM output as a search
hypothesis rather than a fixed interpretation and expose it for inspection and
editing before retrieval.

Interaction has repeatedly been identified as an important component of VBS
search performance. A post-evaluation of VBS 2022 found that strong CLIP-based
text retrieval benefits KIS, but needs to be complemented by effective browsing
and additional query modalities for consistent
performance~\cite{schall2024interactive}. More recent interaction logs from VBS
2026 show a strong reliance on iterative, high-frequency text-query reformulation
coupled with result-set inspection~\cite{jackl2026interaction}. Existing
interactive video retrieval systems provide rich mechanisms for query
formulation, browsing, and relevance feedback~\cite{amato2024visione,lokoc2024prak}; however, for multi-event search, the decoded temporal alignment
of a candidate is typically not exposed as an object that the operator can
directly inspect and modify. Consequently, when several events are matched
correctly but one occurrence is temporally misaligned, the operator may need to
reformulate the query or continue browsing despite already having useful
retrieval evidence. This motivates interaction not only with the input query,
but also with the temporal hypothesis produced for an individual candidate.

To address these two interaction points, we present \textbf{SHI}, an interactive
multimodal video retrieval system for multi-event KIS with complementary
\emph{pre-retrieval} and \emph{post-retrieval} mechanisms.
\textbf{Pre-retrieval Query Hypothesis} exposes the LLM-generated event
decomposition as an editable structured plan, allowing operators to inspect
event boundaries, revise event descriptions, reorder events, and attach visual
reference examples before search. \textbf{Post-retrieval EventTrail} exposes the
decoded temporal alignment of a candidate video as an ordered event path,
allowing operators to inspect alternative occurrences, anchor accepted matches,
and exclude incorrect temporal regions. The resulting constraints are applied
by re-decoding the alignment from retained retrieval evidence without repeating
corpus-level retrieval. Together, these mechanisms make semantic decomposition
before retrieval and temporal alignment after retrieval explicit parts of the
interactive search process.
