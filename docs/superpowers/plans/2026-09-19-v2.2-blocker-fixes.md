### Task 1: Fix event-conditioned DP backward recurrence to enforce strict chronological order

**Problem:** `align_video_conditioned()` in `src/hcmai/temporal/dp.py` uses `np.searchsorted(source, frames, side="left")` for the backward DP successor lookup. `source = (starts - 1).clip(0)` means `source[t=0] = 0`, so `searchsorted(source=[0,0,...], query=0, side="left") = 0` — the same frame is a valid "successor" of itself. This allows two events to occupy the same frame, violating the strict chronology contract `t_i < t_{i+1}`.

Root cause reproduced: for 2-event/2-frame input with focus on E0, the implementation returns path `frame_idx=(0, 0)` with score 1.2, while the only valid strict path is `(0, 1)` with score 0.7.

**Fix:** The backward DP for event `e` at position `t` must find the best successor at a strictly later frame position `>= t+1`. Replace the `searchsorted` approach with a right-to-left suffix-max array indexed at `t+1`.

**Files:**
- Modify: `src/hcmai/temporal/dp.py` (lines 260–284, the backward DP loop)
- Modify: `tests/temporal/test_event_conditioned_dp.py` (add regression tests)

**Interfaces:**
- Consumes: `VideoEventScores` (unchanged)
- Produces: `list[ConditionedDPPath]` — same shape; correctness is the only change

- [x] **Step 3: Fix the backward DP in `src/hcmai/temporal/dp.py`**

Replace the backward loop body (lines 260–284) with this corrected version. The key change: for each position `t`, the earliest valid successor is at `t+1`, not at `searchsorted(source, t)`. Build a right-to-left suffix-max over `shifted_suffix` and index it at `t+1`:

```python
    # 2. Backward DP (suffix)
    suffix = np.full((n_events, n_frames), -np.inf, dtype=np.float64)
    succ = np.zeros((n_events, n_frames), dtype=np.int64)
    suffix[n_events - 1] = scores[n_events - 1]

    for event in range(n_events - 2, -1, -1):
        shifted_suffix = suffix[event + 1] - weighted_time

        # Build a right-to-left suffix-max of shifted_suffix so that
        # best_from_right[t] = max(shifted_suffix[t], ..., shifted_suffix[n_frames-1]).
        # We need size n_frames+1 so that best_from_right[n_frames] = -inf (sentinel
        # for frame t = n_frames-1, which has no valid successor).
        best_from_right = np.full(n_frames + 1, -np.inf, dtype=np.float64)
        best_idx_from_right = np.zeros(n_frames + 1, dtype=np.int64)
        cur_best = -np.inf
        cur_best_idx = 0
        for t in range(n_frames - 1, -1, -1):
            val = shifted_suffix[t]
            if val >= cur_best:
                cur_best = val
                cur_best_idx = t
            best_from_right[t] = cur_best
            best_idx_from_right[t] = cur_best_idx

        # For frame t, the successor must be strictly later: position >= t+1.
        # next_start[t] = t+1; for t = n_frames-1, next_start = n_frames (sentinel).
        next_start = np.arange(1, n_frames + 1, dtype=np.int64)
        valid_succ = (next_start <= n_frames - 1) & np.isfinite(best_from_right[next_start])

        suffix[event] = np.where(
            valid_succ & np.isfinite(scores[event]),
            scores[event] + weighted_time + best_from_right[next_start],
            -np.inf,
        )
        succ[event] = np.where(valid_succ, best_idx_from_right[next_start], 0)
```

```python
def _extract_example_events(prompt: str, needle: str) -> list[str]:
    """Extract numbered event lines following the Input: line containing needle."""
    lines = prompt.splitlines()
    in_example = False
    events = []
    for line in lines:
        stripped = line.strip()
        if stripped.startswith("Input:") and needle in stripped:
            in_example = True
            events = []
            continue
        if in_example:
            if not stripped or stripped.startswith("Input:"):

            # Match lines like "1. ...", "2. ..."
            if len(stripped) >= 3 and stripped[0].isdigit() and stripped[1] == ".":
                events.append(stripped[2:].strip())
    return events
```

### Task 5: Fix language detection for Vietnamese without diacritics

**Problem:** `infer_query_language()` detects Vietnamese only via Unicode diacritics. ASCII-only Vietnamese (e.g., `"nguoi dan ong buoc vao phong"`) returns `"en"`.     """Infer server-owned query language: 'vi', 'en', or 'mixed'.

```python
    Classification is deterministic and bounded to 'vi'/'en'/'mixed'.

    Vietnamese detection uses two independent signals:
    1. Unicode diacritics (NFC/NFD) — high precision.
    2. ASCII Vietnamese function-word heuristic — catches unaccented input.
    """
    normalized = unicodedata.normalize("NFC", query)
    has_vi = any(
        ch in _VI_MARKERS or ("\u0300" <= ch <= "\u036f")
        for ch in unicodedata.normalize("NFD", normalized)
    )
    has_ascii_word = any(
        part.isascii() and part.isalpha() for part in normalized.split()
    )
    if has_vi and has_ascii_word:
        return "mixed"
    if has_vi:
        return "vi"

    # ASCII-only path: check for Vietnamese function words.
    lowered_tokens = {
        part.lower()
        for part in normalized.split()
        if part.isascii() and part.isalpha()
    }
    vi_hits = lowered_tokens & _VI_ASCII_WORDS
    if len(vi_hits) >= _VI_ASCII_THRESHOLD:
        return "vi"
    return "en"
```
