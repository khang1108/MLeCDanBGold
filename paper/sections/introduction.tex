\section{Introduction}
\label{sec:introduction}

The Video Browser Showdown (VBS) evaluates interactive video retrieval systems
through live search tasks over large video collections~\cite{vbs2027cfp}.
In Known-Item Search (KIS), participants translate a description of a
previously observed scene into search operations, inspect retrieved evidence,
and identify a valid frame or video segment. This becomes particularly
challenging when the description contains multiple temporally ordered events:
the system must determine both how the narrative should be decomposed into
retrievable events and where those events occur within a candidate video.

Interactive video retrieval systems provide mechanisms for refining queries,
browsing results, and incorporating user feedback
~\cite{lokoc2023queryreformulation,schall2024interactive,jackl2026interaction}.
Prior VBS evaluations show that effective search depends not only on the
quality of the initial ranking, but also on iterative query reformulation and
result inspection~\cite{schall2024interactive,jackl2026interaction}.
However, for multi-event queries, two intermediate decisions are typically
not directly exposed for correction: the event structure inferred from the
input narrative and the temporal occurrences selected for those events inside
a candidate video.

We present \textbf{SHI}, an interactive video retrieval system that exposes
both decisions as inspectable and correctable hypotheses. Before retrieval,
the \emph{Query Hypothesis} represents the input description as a
source-grounded ordered sequence of retrievable events. Users can inspect and
revise this structure before executing the search, making the interpretation
used for retrieval explicit rather than relying on an implicit query rewrite.

After retrieval, \emph{EventTrail} exposes the temporal hypothesis associated
with a candidate video. Instead of presenting event matches as independent
frames, EventTrail represents them as a complete ordered path through the
video. Users can inspect alternative occurrences for individual events in the
context of the complete sequence and correct inaccurate selections. Committed
corrections are incorporated as constraints and the temporal alignment is
re-decoded accordingly.

The main contributions of SHI are:

\begin{itemize}
    \item an inspectable, source-grounded \emph{Query Hypothesis} that exposes
    the event-level interpretation of a multi-event query and supports explicit
    structural correction;

    \item \emph{EventTrail}, an interactive hypothesis explorer that exposes
    the temporal alignment of a candidate video and incorporates event-level
    corrections into temporal re-decoding; and

    \item an end-to-end VBS system integrating multimodal retrieval, temporal
    alignment, and hypothesis-level interaction for multi-event KIS.
\end{itemize}
