\section{Related Work}

Interactive video retrieval at VBS combines multimodal scoring with iterative
query refinement and result exploration
~\cite{lokoc2021reign,schall2024interactive,jackl2026interaction}.
Recent systems employ foundation models for query assistance: CLIP-based
reformulation suggests textual refinements~\cite{lokoc2023queryreformulation},
Exquisitor incorporates conversational search and foundation models
~\cite{khan2024exquisitor,sharma2025exquisitor,sharma2025foundation}, while
HORUS, NII-UIT, and ViewsInsight2.0 use LLMs for query expansion
~\cite{nguyen2025horus,gia2025niiuit,vuong2025viewsinsight}.
Beyond simple expansion, modular decomposition with LLMs has emerged as an
effective strategy for multi-step tasks~\cite{khot2023decomposed}. Most closely,
SnapMind uses an LLM planner to generate editable retrieval plans
~\cite{hole2026snapmind}. While SnapMind edits system-level tool and index
routing, SHI directly targets narrative semantics, exposing the event-level
decomposition and chronological order as the primary editable object.

Temporal structure has also been explored extensively in video retrieval.
Vireo-VSS supported structured temporal query templates~\cite{wu2021sql}, while
vitrivr introduced multi-stage temporal scoring and multimodal temporal queries
~\cite{heller2020multistage,heller2022temporalqueries}. Recently, Vibro, NII-UIT,
and Exquisitor investigated dynamic and sequence-chain temporal search
~\cite{hezel2022vibro,gia2025niiuit,khan2026temporalqueries}, and automated
event retrieval has used dynamic programming to extract coherent event chains
~\cite{ho2026lucifertrace}. However, these approaches treat temporal alignment as
an automated, one-way ranking process: users cannot inspect how events are assigned
across candidate timelines, nor can they interactively steer the alignment when an
occurrence is misplaced.

SHI therefore does not treat LLM decomposition or temporal alignment as new
retrieval primitives. Grounded in interactive machine learning and mixed-initiative
steering~\cite{amershi2014power}, its focus is direct interaction with intermediate
representations: the Query Hypothesis exposes source-grounded event decomposition
before retrieval, while EventTrail exposes candidate temporal assignments,
converting local user feedback into constraints for full-path re-decoding.
